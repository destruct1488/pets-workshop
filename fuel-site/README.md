# Сайт ТАНКЕР-ОІЛ КОМПАНІ

Корпоративный сайт на Next.js (украинский язык). Цены за регионами обновляются
из Telegram: вы отправляете боту фото таблицы, Claude читает её, бот показывает
результат, и после вашего подтверждения цены появляются на сайте.

Все факты о компании (телефоны, реквизиты, цифры) лежат в `src/lib/site.ts`.
Их взяли из презентации `TANKER_2025.pdf`; чтобы что-то поменять, правьте этот файл.

## Запуск локально

```bash
cd fuel-site
npm install
npm run dev        # http://localhost:3000
npm test           # проверки логики цен и защиты webhook
npm run typecheck
npm run build
```

Без переменных окружения сайт работает, а в блоке цен показывает ссылку на
Telegram-канал.

## Как обновляются цены

1. Вы отправляете фото таблицы боту в личные сообщения.
2. Сайт скачивает фото и передаёт его в Claude API, который возвращает строки
   `регион, товар, цена, единица`.
3. Данные проходят проверку (типы, диапазоны, длины, дубли). Если цена изменилась
   больше чем на 10%, бот предупреждает об этом.
4. Бот присылает расшифровку с кнопками «Опублікувати на сайті» и «Скасувати».
   Без вашего нажатия на сайте ничего не меняется.
5. После подтверждения цены сохраняются и страница обновляется сразу.

Команда `/status` показывает, когда цены обновлялись в последний раз.

## Подключение Telegram (один раз)

1. В Telegram откройте @BotFather, создайте бота командой `/newbot`, получите токен.
2. Узнайте свой числовой Telegram ID (например, через бота @userinfobot).
3. Получите ключ Claude API в консоли Anthropic.
4. Создайте бесплатную базу Upstash Redis (нужна на хостинге, где файлы не сохраняются).
5. На хостинге задайте переменные из `.env.example`:
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` (любая длинная случайная строка),
   `TELEGRAM_ALLOWED_USER_IDS`, `ANTHROPIC_API_KEY`, `UPSTASH_REDIS_REST_URL`,
   `UPSTASH_REDIS_REST_TOKEN`.
6. После деплоя один раз зарегистрируйте адрес бота:
   `SITE_URL=https://ваш-домен TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... npm run set-webhook`

Токены и ключи нигде не храните в коде и не присылайте в чаты.

## Что сделано для безопасности

- Сайт почти полностью статичный: нет админки, логинов, баз и форм, которые можно взломать.
- Webhook принимает запросы только с секретным токеном Telegram (сравнение за
  постоянное время). Без него ответ 401.
- Фото принимаются только из личного чата и только от Telegram ID из списка
  `TELEGRAM_ALLOWED_USER_IDS`. Остальных бот молча игнорирует.
- Ответ модели считается недоверенным: проверяются типы, диапазоны, длины, символы.
  Текст на фото воспринимается как данные, а не как инструкции.
- Публикация только после подтверждения кнопкой; повторное нажатие не публикует дважды.
  Повторная доставка одного и того же сообщения Telegram игнорируется.
- Заголовки безопасности: CSP, HSTS, X-Frame-Options, nosniff, Referrer-Policy,
  Permissions-Policy. Заголовок `X-Powered-By` отключён.
- Зависимости проверены `npm audit`: 0 уязвимостей. Версии зафиксированы в `package-lock.json`.

Ограничение: в CSP разрешён `'unsafe-inline'` для скриптов, потому что Next.js
вставляет служебные скрипты в страницу. Риск небольшой, так как на сайте нет
пользовательского контента и сторонних скриптов. Строгие nonce-ы сделали бы все
страницы динамическими.

Что остаётся за владельцем: двухфакторная аутентификация на GitHub, хостинге,
Upstash и Telegram, перевыпуск токена при подозрении на утечку, ограничение
расходов в консоли Anthropic.

## Деплой

Подойдёт любой хостинг для Next.js (например, Vercel). Укажите папку проекта
`fuel-site`, задайте переменные окружения и подключите домен с HTTPS.

## Формат фото с ценами

Разбор настроен под вашу таблицу: три блока (дизельне пальне, бензин А-95,
пропан-бутан), по строкам регионы, сверху дата. На сайте цены показываются
таблицей «регион × вид топлива» с датой из таблицы.

- Если в таблице не напечатана единица измерения, бот считает цены в `грн/л`.
  Если это не так, поменяйте правило `unit` в `src/lib/vision.ts`.
- Позиции без цены («А-92, А-98 узгодження») на сайт не попадают.
- Условия поставки (ПДВ, объём, DDP) вынесены на сайт текстом в `src/app/page.tsx`,
  потому что они меняются редко.
- Тестовая копия вашей таблицы от 19.11.2026 лежит в `tests/fixtures/`, по ней
  проверяются разбор и отображение.
